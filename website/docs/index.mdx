# Hermes Agent

A personal AI agent for **Linux and macOS**, with encrypted state, tools, memory,
skills, scheduled work, and delegated agents. The CLI, TUI, desktop source app, and
messaging gateway share one agent core.

:::note Unofficial fork
This is [majorissuerep/hermes-agent](https://github.com/majorissuerep/hermes-agent),
an unofficial fork of [NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent).
It is not supported or endorsed by Nous Research. Commands here install this fork;
report problems to the [fork issue tracker](https://github.com/majorissuerep/hermes-agent/issues).
:::

## Product scope

The priority is dependable everyday use: a conversation that grows and resumes
correctly, encrypted self-management, and safe installation, update, and recovery.
A small maintained surface matters more than the number of integrations.

Choose from the [supported provider catalog](./integrations/providers.md):
ChatGPT/Codex, Anthropic, OpenAI API, LiteLLM, custom OpenAI or Anthropic endpoints,
Z.AI, Grok, and Vercel AI Gateway. A custom URL or optional plugin does not imply
support for every vendor behind it. See the
[platform policy](./getting-started/platform-support.md) and
[reliability contract](./developer-guide/reliability.md).

## Install

Review [what the installer does](./getting-started/installation.md), then run on
Linux or macOS (Windows hosts use a WSL2 Linux distribution):

```sh
curl -fsSL https://raw.githubusercontent.com/majorissuerep/hermes-agent/main/scripts/install.sh | bash
hermes secure-vault status
hermes model
hermes
```

If no vault exists, follow [encrypted-state setup](./getting-started/installation.md#initialize-encrypted-state)
before model setup. For an existing upstream installation, use the
[migration instructions](./getting-started/installation.md#switch-existing-installation).
Upstream desktop downloads and package feeds do not install this fork.

## Everyday use

Unlock once per session. Local Hermes commands and delegated agents reuse
temporary, home-scoped authority without receiving the passphrase. A standalone
update unlocks once. Use the CLI's encrypted writers for configuration changes.

```sh
hermes config check
hermes update
hermes doctor
```

See [encrypted state and recovery](./user-guide/encrypted-state.md) before repairing
damaged files or exporting decrypted state. Never repair by deleting the state home.
